# ACE Classification and Pattern Identification

This component uses the preprocessed BRFSS 2023 data for 35,754 respondents aged 45 years or older. First, 11 binary adverse childhood experience (ACE) items are validated and summed to classify respondents into four score groups: 0, 1, 2–3, and 4+. The analysis describes group distributions, pairwise ACE co-occurrence, exact exposure combinations, and demographic composition by sex, age, education, income, marital status, and race/ethnicity. Binary latent class analysis (LCA) then compares models with different numbers of classes. Balancing model fit, classification quality, and interpretability, a five-class solution is adopted: Low ACE exposure, Physical and verbal abuse, Sexual abuse-dominant, Household dysfunction, and Multiple ACE exposure. Demographic characteristics and subjective cognitive decline (SCD) percentages are subsequently described within these classes.

This is the English companion to [README.md](README.md). The original Chinese notebooks and README are retained unchanged. Both English notebooks are self-contained and require no local Python scripts. They retain analysis tables and figures but do not generate or display a final report.

The primary notebook reads the input CSV and regenerates its outputs on every run. The LCA notebook uses:

```python
REFIT = True
```

- `True`: refit all candidate models from the CSV, using seed `20261102`, 30 random starts for each K=2–6 model, and one start for the K=1 baseline. The adopted solution is `selected_k=5`.
- `False`: read the existing **English** LCA outputs. A missing `english/lca/models/selection.json` triggers fitting. This mode requires the associated models, classified data, and result tables, not just the JSON file. Use `True` after changing the input or estimation settings.

EM allows up to 10,000 iterations and declares convergence when the absolute change in log-likelihood is below `1e-5`. Rerunning an analysis updates its corresponding English data, tables, models, and figures. It does not update either README automatically.

## Five-class LCA: selection and results

Binary LCA is implemented as a finite mixture of conditionally independent Bernoulli distributions. The 11 binary ACE indicators are the inputs. Maximum likelihood is estimated with EM, and a five-class model is adopted after comparing K=1–6. SCD and demographic variables do not enter model estimation.

### Estimation and model comparison

The n=35,754 respondents have 1,020 distinct response patterns. Aggregating identical responses by their counts is equivalent to the individual-level unweighted likelihood. The number of free parameters is p=11K+K−1; AIC=−2LL+2p and BIC=−2LL+p log(n). Model fitting is unweighted; survey weights are used only for subsequent descriptive summaries. This is not a complex-survey-weighted LCA.

Normalized classification entropy is 1 + sum(r_ic log(r_ic))/(n log K), where r_ic is the posterior membership probability. Values closer to one indicate clearer separation. Entropy is undefined for K=1 and is not sufficient on its own to select K.

| K | AIC | BIC | Entropy | Smallest model class % | Best-likelihood replications |
|---|---:|---:|---:|---:|---:|
| 1 | 303915.6 | 304008.9 | Not applicable | 100.00 | 1 |
| 2 | 267721.1 | 267916.2 | 0.817 | 23.35 | 30 |
| 3 | 259922.7 | 260219.6 | 0.830 | 7.80 | 30 |
| 4 | 257561.9 | 257960.7 | 0.847 | 3.87 | 21 |
| 5 | 256397.5 | 256898.0 | 0.816 | 3.83 | 17 |
| 6 | 255429.5 | 256031.9 | 0.771 | 3.56 | 28 |

The adopted five-class model has entropy 0.816. Overall, 13.79% of respondents have a maximum posterior probability below 0.70. Classes are ordered by expected ACE item count; class IDs are not diagnostic labels.

#### Rationale for adopting five classes

Five classes balance fit, classification quality, complexity, and interpretability. Although the six-class model has lower AIC and BIC, the five-class model has higher entropy (0.816 versus 0.771), indicating relatively clearer separation. Compared with four classes, the five-class solution provides more differentiated exposure profiles, distinguishing a household-dysfunction profile from a physical/verbal-abuse profile. The five interpretable profiles are Low ACE exposure, Physical and verbal abuse, Sexual abuse-dominant, Household dysfunction, and Multiple ACE exposure.

This is a researcher choice favoring interpretability and parsimony, **not evidence that information criteria favor five over six classes**. The five-class BIC exceeds the six-class BIC by 866.18. The four-class model also has higher entropy (0.847), so five classes do not have the best classification quality across all candidates. Six classes are retained as the better-fitting comparison model.

#### Stability, sample sizes, and posterior classification quality

All 30 five-class starts converged, and 17 replicated the best log-likelihood within 0.01. This supports numerical reproducibility but is not equivalent to bootstrap stability of population classes.

Simple posterior weighting is not a BCH or corrected three-step estimator and does not replace appropriate distal-outcome analysis. Subsequent outcome analyses should not treat modal classes as error-free true categories.

### Diagnostics and limitations

The largest absolute difference between observed and model-predicted pairwise joint prevalence is 1.40 percentage points; see [pairwise residuals](english/lca/tables/pairwise_model_residuals.csv). This is a descriptive diagnostic, not a formal local-independence test. The three sexual abuse items may retain additional dependence, and additional classes may reflect that dependence rather than distinct population subtypes.

Diagnostics include replicated likelihoods across starts, convergence, boundary probabilities, class sizes, and complete response profiles. The adopted five-class solution is exploratory, not a validated population taxonomy. No bootstrap class-enumeration test or complex-survey adjustment was performed. State coverage, complete-case selection, recall error, and sample weighting limit generalizability.
